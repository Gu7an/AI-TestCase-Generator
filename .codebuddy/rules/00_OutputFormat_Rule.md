# Output Format Rule

## Role

本规则规定**所有任务最终交付物**的文件格式与**交付范围**。

它是全体系唯一真源，其他规则、`commands/`、`skills/`、`agents/` 只引用，不复述。

---

# 1. Core Rule

```text
凡是给用户查看的结果性文档，一律交付 .xlsx Excel 文件。

测试用例类交付物，只交付「测试用例」与「冒烟测试用例」两部分。
```

不展示（不写入交付文件、不建 Sheet、不在对话展开）的内容：

```text
需求分析摘要 / 功能拆解 / 业务规则 / 测试场景矩阵 / 规则矩阵
需求覆盖检查与覆盖率报告 / 遗漏补充 / 重复与无效用例处理 / 需求待确认
风险分析、依赖清单、追踪矩阵等内部分析产物
```

上述内容属于**内部分析过程**，仍必须按 `00_Main` 的 18 步流程与 `06` 的十段顺序完整执行并通过质量检查，
只是不进入交付物。禁止以「不展示」为由跳过分析、覆盖率检查或去重。

对话回复只提供：

```text
简短结论 + 文件路径 + 关键数字
```

不得粘贴用例表正文、规则矩阵或覆盖率报告。

# 3. Excel 工作簿结构

```text
一份交付 = 一个 .xlsx 工作簿
```

## 3.1 测试用例类交付（交付范围）

Sheet 顺序固定，且**只允许 2 个 Sheet**：

| 顺序 | Sheet | 内容 | 内部来源 |
|---|---|---|---|
| 1 | `测试用例` | 全部正式测试用例 | `06` 第五段 |
| 2 | `冒烟测试用例` | 从 P0 中筛选的冒烟用例 | `06` 第十段 |

两个 Sheet 均使用同一套 9 列标准字段：

```text
用例ID / 一级模块 / 二级模块 / 前置步骤 / 用例名称 / 测试点 / 优先级 / 操作步骤 / 预期结果
```

要求：

- 冒烟 Sheet 与主表字段口径完全一致，保证可直接复制执行；不得只给 5 列摘要
- P0 / P1 / P2 用例合并为一张连续表，不拆表、不重复表头
- 首行冻结、开启自动筛选、单元格自动换行
- 优先级列按 P0 / P1 / P2 标识（配色可选）
- 用例按风险降序排列，静态展示类置于末尾

## 3.2 其他交付

- 按内容模块分 Sheet，至少包含一个 `说明` Sheet（记录来源、日期、口径）
- 同一主题的多张表格合并到同一 Sheet 或分 Sheet，禁止一个表格一个文件

## 3.3 通用格式

```text
[ ] 统一专业字体（Arial）
[ ] 表头加粗、底色区分、首行冻结
[ ] 列宽按内容自适应并设置上限，长文本自动换行
[ ] 表格区开启自动筛选
[ ] 无公式错误（#REF! / #DIV/0! / #VALUE! / #N/A / #NAME?）
[ ] 不得出现合并单元格导致表格无法筛选或排序
[ ] 冒烟用例均来自主表且优先级为 P0
```

# 4. 文件命名与保存

```text
<项目或主题>-<交付物名称>-<YYYYMMDD>.xlsx
```

示例：`避雷app-测试用例-20261109.xlsx`

- 新建文件统一保存到用户指定根目录 `F:\codeb`；修改已有项目时保持原项目目录
- 若结果视图只支持工作区内的文件，需在工作区保留同名副本用于展示，主文件仍在 `F:\codeb`
- 按新规则修订已有交付物时，覆盖同名文件即可，不另建版本文件

---

# 5. Forbidden

禁止：

1. 只生成 `.md` / `.txt` / `.docx` / `.pdf` / `.csv` 作为最终交付
2. 以「可直接复制到 Excel」代替真正生成 Excel 文件
3. 把完整报告正文或用例表粘贴在对话里而不产出文件
4. 在交付物中输出需求分析、业务规则、场景/规则矩阵、覆盖率报告、遗漏补充、需求待确认等非用例章节
5. 交付物中出现第 3 个及以上 Sheet（测试用例类）
6. 冒烟 Sheet 使用与主表不同的字段口径，或包含非 P0 用例
7. 用例表缺列、重复表头、合并单元格导致无法筛选
8. 因「不展示」而跳过 18 步分析、覆盖率检查、去重或优先级评估

---

# 6. Exceptions

以下不受本规则约束：

- 源代码、配置、依赖清单、工程 README 等工程文件（`.py` / `.json` / `.ini` / `.yml` / `requirements.txt` 等）
- 用户**当次明确指定**了其他格式或要求展示分析内容（当次指令优先于长期偏好）
- 纯问答类请求，本身不产生交付文档

内部分析产物与中间过程文件不属于交付物，用完即清理，不落盘为交付文件。

---

# 7. Quality Gate

声明任务完成前必须确认：

```text
[ ] 已生成 .xlsx 文件（不是"可复制到 Excel"的描述）
[ ] 18 步分析与十段内部检查已完整执行并达标（只是不展示）
[ ] 交付物仅含 2 个 Sheet：测试用例 / 冒烟测试用例
[ ] 两个 Sheet 均为 9 列同一字段口径、单一表头、可筛选
[ ] 冒烟用例全部来自主表且均为 P0
[ ] 文件命名与保存位置符合第 4 节
[ ] 已通过结果视图打开 .xlsx 交付物
```
