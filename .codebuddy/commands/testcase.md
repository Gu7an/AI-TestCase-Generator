# Test Case Command

请使用 `test-analyst` Agent 执行完整测试分析。

使用：

`test-case-generation` Skill。

必须按照以下流程：

需求理解
→ 需求分析
→ 功能拆解
→ 业务规则分析
→ 场景分析
→ 领域风险分析
→ 风险场景补充
→ 测试用例生成
→ 质量检查
→ 覆盖率检查
→ 遗漏补充
→ 去重
→ 优先级
→ 冒烟测试
→ 最终输出

不得跳过质量检查和领域风险检查。

如果需求信息不足：

1. 明确指出缺失信息
2. 不得虚构业务规则
3. 必要时使用明确标记的假设继续分析
